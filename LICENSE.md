# Notes on the discerns License

I wrote the discerns License with two goals in mind:

1. To stop people from publishing services built from discerns that contain
   malware or misuse their users' data, or that look just like discerns except
   that when you subscribe, someone other than me gets paid.
2. To let everyone else do anything they like with the discerns source code.
   That includes reusing it in their own free and paid projects, publishing bug
   fixes and improvements to discerns, running it for themselves or their own
   team, and building something substantially better on top of discerns and
   charging for it.

There are no restrictions on how you use the source code. You can read it,
change it, build it, and run it yourself, including privately for your own team.
The restrictions only apply to publishing a program or offering a service built
from it to other people.

discerns is source-available, not open source. The Open Source Definition from
the Open Source Initiative does not allow conditions like the ones above, so
this is not an OSI-approved open source license.

discerns is a hosted service at https://discerns.app with a free plan and a paid
Pro plan. Subscribing to Pro pays for using the hosted service. It does not
change these terms, and you do not need a subscription to use the source code.
